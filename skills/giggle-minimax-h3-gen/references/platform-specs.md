# MiniMax-H3 平台参数与限制（giggle.pro）

> **成片入口：** [giggle.pro](https://giggle.pro)（`scripts/generation_api.py`）。  
> **计费 / 生成模式**与 storyclaw-token-gateway MiniMax-H3 对齐；素材须为公网 URL。

## 输入规格

| 维度 | 规格 |
|------|------|
| **图片** | 公网 URL，≤9 张；图生 1 张、首尾帧 2 张 |
| **视频** | 公网 URL，≤3 个；平台探测时长，勿传 `video_durations` |
| **音频** | 公网 URL，≤3 个，不计费 |
| **分辨率** | `480p` / `768p`（默认 `768p`） |
| **时长** | 4–15 整数秒（默认 5） |
| **画幅** | `16:9` / `9:16` / `1:1` / `4:3` / `3:4` / `21:9` / `auto`；省略则不传 |
| **混合上限** | 图片+视频+音频合计建议 ≤12 |

## 生成模式

| 模式 | `task` | 说明 |
|------|--------|------|
| 文生 | `Txt2Video` | 仅 `prompt` |
| 图生 | `Img2Video` | `images` 恰好 1 |
| 首尾帧 | `Img2Video` | `images` 恰好 2（首、尾） |
| 全能参考 | `OmniVideo` | images / videos / audios 至少一项 |

## @引用命名

| 类型 | 命名 | 上限 |
|------|------|------|
| 图片 | `@图片1` … `@图片9` | 9 |
| 视频 | `@视频1` … `@视频3` | 3 |
| 音频 | `@音频1` … `@音频3` | 3 |

提示词里的编号习惯须通过 CLI/`input` **全部**传入对应 URL。计费细则见 [billing.md](billing.md)。
