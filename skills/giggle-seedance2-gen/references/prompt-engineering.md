> **平台覆盖声明**：本文件为通用提示词工程规范。凡涉及「即梦平台」「NanoBanana」「即梦图片生成」的内容，在本仓库中以根目录 `SKILL.md` 的 Giggle 平台约束为准（含语言规则、API 参数、@引用限额）。

## ⚠️ 最重要的事：先想清楚"做什么"，再考虑"怎么写"

提示词写得再精致，如果概念本身不吸引人，出来的视频也只是"技术上正确的平庸"。

**在动手写提示词之前，必须先明确：**

1. **≤15秒**：不要讲故事，做一个"不可能的瞬间"。前2秒必须抓人。概念越简单越好，一个视频只做一件事。
2. **>15秒**：不要指望一条提示词一步到位。必须走完整前期流程：角色卡片图 → 分镜脚本 → 分镜参考图 → 逐镜头生成 → 后期拼接。
3. **参考素材优先**：大部分好的 AI 视频不是纯文本生成的。先做首帧图、找参考视频，再写提示词。

详见 [creative-strategy.md](creative-strategy.md)（创意策略）和 [production-pipeline.md](production-pipeline.md)（长视频生产流水线）。

## 核心能力速查

Seedance 2.0 = **多模态参考能力（可参考万物）** + 强创意生成 + 精准指令响应

| # | 能力 | 提示词核心模式 |
|---|------|---------------|
| 1 | **一致性控制** | `[角色]@图片N + [动作/剧情] + [场景]@图片N` |
| 2 | **运镜/动作复刻** | `参考@视频1的[运镜/动作/节奏] + [主体]@图片N` |
| 3 | **创意/特效复刻** | `参考@视频1的[特效/转场] + 将[元素]替换为@图片N` |
| 4 | **剧情补全** | `[分镜脚本/图片描述] + [演绎方式] + [音效/台词]` |
| 5 | **视频延长** | `将@视频1延长Xs + [新增内容]` |
| 6 | **声音控制** | `[画面] + 音色参考@视频1 + "台词"` |
| 7 | **一镜到底** | `一镜到底 + @图片1@图片2... + 全程不切镜头` |
| 8 | **视频编辑** | `将@视频1中的[A]换成@图片1 + [修改说明]` |
| 9 | **音乐卡点** | `@图片1...@图片N + 参考@视频1的画面节奏/卡点` |
| 10 | **情绪演绎** | `[角色] + [情绪变化描述] + [运镜配合]` |

各能力的详细示例见 [examples.md](examples.md)。

## 提示词结构模板

### 基础结构（≤12秒短视频）

```
[风格/色调总纲]，[主体描述]，[动作序列]，[环境/光影]，[镜头语言]，[音效描述]
```

### 时间戳分镜法（13–15秒，强烈推荐）

```
[时长][风格总纲]，
0-3秒：[画面 + 镜头 + 音效]；
4-8秒：[画面 + 镜头 + 音效]；
9-12秒：[画面 + 镜头 + 音效]；
13-15秒：[画面 + 镜头 + 音效]。
```

### 短剧/对白结构

```
画面（0-5秒）：[画面描述]
台词1（角色，情绪）：[台词内容]
画面（6-10秒）：[画面描述]
台词2（角色，情绪）：[台词内容]
音效：[音效描述]
时长：精准Xs
```

### 史诗/大制作结构（科幻/灾难/奇幻/动作等高品质视觉作品）

```
[时长][品质锚定：渲染引擎+画质规格+VFX等级]，[核心氛围宣言：美学风格+整体感受]，
[大气连贯声明：全片统一的物理/氛围效果，如"每帧都有薄雾弥散效果"]，

0-Xs：[画面动作] + [运镜] + [可选逐段帧率，如"慢镜头120帧/秒"] + [大气在本段的具体表现]；
...（时间戳分镜继续）...

光影：[①光源：主光类型和角度] + [②光行为：如何影响大气/材质] + [③色调：冷暖对比]，
[收束句：后期处理词叠加] + [张力宣言：一句话锚定全片情绪]。
```

> **与基础结构的四点核心差异：**
> 1. **品质锚定**：开头声明渲染引擎/VFX等级（"UE5渲染，工业光魔级VFX"），效果远优于泛词"电影感"
> 2. **大气连贯声明**：全片统一物理效果（"每帧薄雾弥散"），防止不同镜头氛围断裂
> 3. **光影三层**：光源 → 光行为 → 色调，三层各司其职，精准度远高于泛写"光线好"
> 4. **收束句**：后期处理词 + 张力宣言，为全片定格情绪与视觉风格

## 运镜三级进阶

运镜是决定视频质量的关键。Seedance 2.0 对中英文混合描述效果更好。

1. **基础动作**：Pan/摇移、Dolly/推轨、Zoom/变焦、Crane/升降、Orbit/环绕、Tracking/跟踪（覆盖 80% 需求）
2. **修饰词**：速度（Smooth/Slow/Fast）、情绪（Cinematic/Dreamy/Aggressive）、风格（Handheld/Aerial/POV）
3. **组合技**：Orbit + Zoom In、Crane Up + Pan、Dolly Zoom（一次最多 2–3 个，用 `+` 连接）
4. **镜头质感修饰**（隐藏层级）："雾水珠附着镜头前"、"雾粒粘镜"、"镜头轻微抖动"——这类"不完美"效果反而大幅提升真实感和沉浸感。

完整运镜体系见 [vocabulary.md](vocabulary.md)。

## 图片生成提示词（角色参考图 & 首帧图）

图片生成是视频生产流水线的关键前置步骤，详见 [image-generation.md](image-generation.md)。

### 角色参考图 prompt 格式

```
9:16竖版构图。[风格锚定]角色设定图，[构图视角]，[背景]，角色居中。[面部7要素]。[发型]。[头饰]。[服装逐件+新旧状态+污渍]。[道具]。[体态气质]。[光影]。[画质]。禁止：任何文字、字幕、LOGO、水印、多余背景元素
```

### 首帧图 prompt 格式

```
[画幅比]。[风格锚定]，[构图+角色位置]。[角色状态+关键辨识特征]。[环境细节]。[光影层次]。[色调氛围]。[画质]。禁止：任何文字、字幕、LOGO、水印
```

## 提示词质量自检 Checklist

**视频提示词：**
- [ ] @引用编号与素材清单一一对应
- [ ] 总文件数 ≤ 12（图片+视频+音频）
- [ ] 未包含写实真人面部素材
- [ ] 时间戳分镜覆盖完整时长，无遗漏
- [ ] 台词用引号包裹并标注角色和情绪
- [ ] 音效描述与画面描述分开
- [ ] 超长视频衔接点描述清晰
- [ ] 超长视频已加入风格锁定、角色锁定、场景锁定语句
- [ ] 延长段开头已安排桥接镜头或尾帧延续微动
- [ ] 统一负面提示词已覆盖风格漂移、角色变脸、偏色、光线突变等风险

**图片提示词（角色图/首帧图）：**
- [ ] 角色参考图画幅比为 9:16 竖版
- [ ] 首帧图画幅比与原视频一致
- [ ] 全部中文描述（本仓库默认；英文用户则全英文）
- [ ] 末尾有禁止项声明

## 关键提示词技巧

**节奏与传播：**
- **前2秒是生死线**：最震撼的视觉放在开头，禁止用"缓缓推进"开场
- **一个视频一件事**：15秒内只做一个核心概念
- **参考素材 > 纯文本**：大部分优质AI视频都用了首帧图或参考视频引导
- **静→动的突变比持续运动更有冲击力**

**大制作进阶：**
- **品质锚定开头**："UnrealEngine5渲染，工业光魔级VFX特效"比泛词"电影感"更精准
- **大气连贯声明**：全片统一物理效果（"每帧都有薄雾弥散效果"），防止分镜间氛围断裂
- **光影三层结构**：光源 → 光行为 → 色调，三层各司其职
- **镜头污染增强真实感**：雾粒粘镜、雨水附着镜头前等"不完美"效果提升沉浸感
- **收束句定格全片情绪**：结尾写后期处理词 + 张力宣言
